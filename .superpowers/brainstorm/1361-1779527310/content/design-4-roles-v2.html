设计确认 · 第四节（修订）：4人团队分工

每人负责一个完整模块，后端2人 + 前端2人

角色分配方案（4人）

角色 1：后端架构 + 用户系统

Django 项目搭建、User/Dataset/AnalysisTask/ChartConfig 四个模型、DRF + JWT 认证、文件上传/预览/导出 API、数据集 CRUD。

交付：认证可用的后端骨架 + 数据管理 API

角色 2：数据清洗 + 分析算法

Pandas 数据加载与清洗（缺失值/异常值）、统计报告生成、scikit-learn K-Means + 线性回归、结果转图表 JSON、算法效果评估指标。

交付：清洗 + 聚类 + 回归完整分析链路

角色 3：前端架构 + 基础页面

Vue 3 + Vite 项目搭建、路由配置、Pinia stores、Axios 封装、登录/注册/Dashboard/Upload/Clean 页面、DataTable/FileUploader/NavBar 组件。

交付：前端骨架 + 数据管理流程可跑通

角色 4：可视化 + 部署文档

ECharts 集成、ChartPanel/ChartConfig 组件、Analysis/Visualize/History 页面、图表配置面板（散点/折线/柱状/热力/箱线/饼图）、Django+Vue 部署配置、实验报告。

交付：6种可配置图表 + 部署文档

开发阶段（5 阶段并行推进）

阶段 角色1 (后端架构) 角色2 (算法) 角色3 (前端骨架) 角色4 (可视化)
1. 搭建 Django+模型+JWT 数据集准备+调研 Vue+路由+Axios ECharts 集成调研
2. 数据流 上传/预览/导出 API 清洗逻辑+统计报告 Dashboard+Upload页 ChartPanel 基础组件
3. 核心功能 分析任务 API K-Means+回归实现 Clean 页+DataTable Analysis+Visualize页
4. 图表系统 图表 JSON 数据 API 算法评估指标 History页+响应式 ChartConfig配置面板
5. 集成 后端联调+bug修复 前端联调+部署+报告
