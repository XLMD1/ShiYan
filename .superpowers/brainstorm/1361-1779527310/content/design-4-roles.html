设计确认 · 第四节：团队角色分工

5-6 人团队，前后端并行开发

角色分配方案

角色 1：后端组长 + 数据模型

负责 Django 项目搭建、User/Dataset/AnalysisTask/ChartConfig 四个模型设计、DRF 配置、JWT 认证中间件。把控后端整体架构。

关键交付：用户可注册登录，文件可上传入库

角色 2：数据清洗 + 导出

负责 Pandas 数据加载、缺失值处理（均值/中位数/删除）、异常值检测（IQR/Z-score）、数据统计报告生成、CSV/Excel 导出。编写 cleaning.py。

关键交付：清洗接口返回前后对比报告

角色 3：分析算法 + 图表数据

负责 scikit-learn K-Means 聚类（肘部法则选K、轮廓系数）、线性回归（R²/MSE评估）、结果转为图表 JSON 数据。编写 clustering.py / regression.py / visualization.py。

关键交付：分析接口返回聚类结果+回归拟合数据

角色 4：前端组长 + 核心页面

负责 Vue 3 项目搭建（Vite）、路由配置、Pinia stores、Axios 封装、登录/注册/Dashboard/Upload 页面。把控前端整体架构和组件规范。

关键交付：前端骨架跑通，认证流完整

角色 5：可视化 + 分析页面

负责 ECharts 集成、ChartPanel/ChartConfig 组件、Analysis/Visualize 页面、图表配置面板（类型选择/轴映射/颜色）、分析结果展示。

关键交付：6种图表可配置生成

角色 6（可选）：测试 + 部署 + 文档

负责前后端联调测试、接口测试、响应式布局适配、Django+Vue 部署配置、实验报告撰写。如果只有5人，此角色由前后端组长分担。

关键交付：部署文档 + 实验报告

开发阶段规划

阶段 后端 (角色1-3) 前端 (角色4-5) 接口对接
1. 项目搭建 Django项目+模型+JWT Vue项目+路由+Axios 认证 API 联调
2. 数据管理 上传/预览/导出 API Upload + Dashboard 页 文件上传联调
3. 数据清洗 清洗逻辑+统计报告 Clean 页 + DataTable 清洗结果展示
4. 分析可视化 K-Means+回归+图表JSON Analysis + Visualize 页 分析+图表联调
5. 集成部署 静态文件服务配置 build + 部署测试 全流程联调
