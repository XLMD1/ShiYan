设计确认 · 第二节：数据模型 & API 设计

Django ORM 模型关系 + REST API 端点清单

核心数据模型 (ER 关系)

4 个核心模型，外键关联
User (Django 内置)
│ id, username, email, password, date_joined
│
├── 1:N ── Dataset
│      id, user(FK), name, file_path, file_type(CSV/Excel),
│      rows, columns, uploaded_at, is_cleaned
│
├── 1:N ── AnalysisTask
│      id, user(FK), dataset(FK), task_type(KMeans/Regression),
│      parameters(JSON), result_data(JSON), metrics(JSON),
│      created_at, status(pending/running/done/error)
│
└── 1:N ── ChartConfig
       id, user(FK), analysis_task(FK), chart_type,
       x_column, y_column, color_column, title,
       config(JSON), created_at

REST API 端点

共 16 个 API，按模块分组
认证模块 POST /api/auth/register/   # 注册 POST /api/auth/login/     # 登录，返回 Token GET /api/auth/me/       # 当前用户信息 数据管理模块 POST /api/datasets/upload/  # 上传文件 + 解析元信息 GET /api/datasets/      # 我的数据集列表 GET /api/datasets/{id}/   # 数据集详情 GET /api/datasets/{id}/preview/ # 前100行预览 (支持分页) DELETE /api/datasets/{id}/   # 删除数据集 数据清洗模块 POST /api/datasets/{id}/clean/ # 执行清洗，返回清洗报告 GET /api/datasets/{id}/stats/  # 数据概览：缺失值/异常值/分布 GET /api/datasets/{id}/export/ # 导出清洗后数据 (CSV/Excel) 分析模块 POST /api/analysis/kmeans/  # 执行 K-Means，参数: K值、特征列 POST /api/analysis/regression/ # 执行线性回归，参数: 自变量/因变量 GET /api/analysis/tasks/   # 分析历史记录 GET /api/analysis/tasks/{id}/ # 单次分析详情+结果 可视化模块 POST /api/charts/generate/  # 根据配置生成图表数据 (返JSON给ECharts) GET /api/charts/configs/   # 用户保存的图表配置
