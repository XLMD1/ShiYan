可复用组件清单

组件 职责 被哪些页面使用
NavBar.vue 顶部导航 + 用户头像 + 退出 全部页面
FileUploader.vue 拖拽上传 + 文件类型校验 + 进度条 Upload
DataTable.vue 通用表格：排序、分页、列筛选 Upload, Clean, History
ChartPanel.vue ECharts 渲染容器，接收 option 配置 Visualize, Analysis
ChartConfig.vue 图表配置面板：类型/轴/颜色选择器 Visualize
AnalysisParams.vue 算法参数表单：K值/特征列/因变量 Analysis
StatsCard.vue 统计指标卡片：均值/方差/缺失率 Clean, Dashboard

状态管理 (Pinia Stores)

  • authStore — 用户登录状态、Token 管理、自动刷新
  • datasetStore — 当前数据集、预览数据、清洗状态
  • analysisStore — 分析任务状态、结果缓存
  • chartStore — 图表配置、ECharts option 生成
